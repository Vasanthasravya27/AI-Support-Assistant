# Plans and Usage Limits

## Free plan
Up to 3 users, 1 GB of storage, and 1,000 API requests per day. Community support only.

## Pro plan
Up to 25 users, 100 GB of storage, and 50,000 API requests per day. Email support with a first response within 24 hours.

## Enterprise plan
Unlimited users, custom storage, single sign-on (SSO), audit logs, and a dedicated support engineer with a 1 hour first response time for critical issues.

## Rate limits
When you exceed your daily API request limit the API returns HTTP 429. Limits reset every day at 00:00 UTC. Upgrade your plan or contact support to request a temporary increase.
